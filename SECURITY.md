# Security Policy

This project is an early research scaffold. Security fixes target the current `main` branch.

Do not report vulnerabilities or patient information in public issues. Use GitHub private reporting:
https://github.com/tranvanhuy-hichan/omniseg/security/advisories/new

Include the affected commit, impact and minimal reproduction using synthetic data.
Never attach identifiable scans, credentials or private dataset links.
Only process files and model checkpoints from sources you trust. Dependencies have their own security policies.
